# M8 — API, UI, Docker

## What we built
- FastAPI app (`api/app.py`): `/chat`, `/sessions/{id}`, `/approvals`, `/approvals/{id}`, `/health`, `/demo/attack`, `/`.
- One-page console (`ui/index.html`): chat, defense selector, approval queue with justification and excerpt, attack demo.
- `wiring.py::build_runtime` shared by CLI and API; Dockerfile (bakes the embedding model) and docker-compose.

**Why this design.** The API is a thin layer over `Conversation`; all logic stays in the graph. A process-wide lock
serialises graph runs because SQLite connections are shared — honest about being a demo, not a scaled service.

## Key concepts
- **Defense level is fixed per session** (409 if changed) — the system prompt can't change mid-conversation.
- **Chat is blocked while an approval is pending** (409) — otherwise a new user turn would orphan a tool call.
- **`docker compose up` works without a key**: compose defaults `TRUSTDESK_PROVIDER` to `fake`.

## Verify it yourself
- `uv run pytest tests/integration/test_api.py -v`.
- `docker compose up --build`, open http://localhost:8000, press Attack demo.

## Interview questions
1. **Why return 409 when a session has a pending approval?** The last assistant message contains a `tool_use` with
   no `tool_result` yet; appending a user message would produce an invalid transcript. The approval must resolve first.
2. **How would you scale this?** Postgres for the store and checkpointer, one graph per worker, per-session locks
   instead of a global lock, approvals pushed via a queue/websocket, and authenticated approvers (out of scope here).
3. **Why bake the embedding model into the image?** So hybrid retrieval works offline and start-up doesn't depend on
   a download; the fallback to BM25 still exists if it's missing.

## Break-it exercise
Remove the `existing.get("defense_level") != req.defense_level` check in `api/app.py::chat`, then send one message at
D3 and the next at D0 to the same session. Expected: no error — but the system prompt in state no longer matches
the conversation's level; with a real model the behaviour silently changes mid-conversation, and the trajectory no longer matches one defense level. Restore the check.
