# M6 — Observability

## What we built
- `observability/tracing.py::Tracer`: one event per model call, tool call, approval and guard, keyed by a 32-hex
  trace ID; JSONL always, Langfuse when keys are set.
- `observability/usage.py`: token and seconds accounting (local inference costs $0, so time is the budget).
- Per-episode tokens, model seconds and latency in `results/<run>/episodes.jsonl`; trajectories link the trace ID.
- `trustdesk trace <trace_id>` viewer.

**Why this design.** Traces are what you debug agents with; JSONL is grep-able, committed alongside results, and
needs no service. Langfuse adds a UI but is optional (ADR-005).

## Key concepts
- **What to record per model call**: model, input/output tokens, latency, stop reason. With a local model, latency
  is the cost you pay, and contention (other models loaded in Ollama) shows up here first.
- **Prefix reuse**: Ollama skips re-reading an unchanged prompt prefix; a constant system prompt keeps that working.
- **Trace ID reuse**: our hex ID is a valid OpenTelemetry/Langfuse trace ID, so both sinks show the same trace.

## Verify it yourself
- `make chat-fake`, talk once, then find the trace file under `data/traces/` and run `uv run trustdesk trace <id>`.
- `make chat`, talk for a few turns, then `trustdesk trace <id>`: latency per call shows where the time goes (and whether another model was loaded in Ollama).

## Interview questions
1. **What's the first thing you look at when an agent episode fails?** The trace: the sequence of tool calls and
   their error codes. A `NOT_VERIFIED` first means skipped verification; `POLICY_DENIED` repeatedly means policy
   misreading; a model call with `stop_reason=max_tokens` means thinking ate the budget.
2. **How do you measure efficiency when inference is free?** Tokens and wall-clock: model seconds per conversation,
   latency p50/p95, tool calls and turns. The simulator's time is reported separately because it isn't product cost.
   With a hosted API you'd multiply tokens by dated per-token prices; the plumbing is the same.
3. **Why keep JSONL if you have Langfuse?** Results must be reproducible from committed files; a hosted UI can
   disappear or change. JSONL links each number to raw evidence.

## Break-it exercise
Set `TRUSTDESK_NUM_CTX=2048` and run `make chat`. Expected: the agent forgets the policy or tools (Ollama truncates
the front of the prompt to fit). Diagnose from `trustdesk trace <id>`: `input_tokens` stops growing near 2048.
Restore the default (16384).
