# M6 — Observability

## What we built
- `observability/tracing.py::Tracer`: one event per model call, tool call, approval and guard, keyed by a 32-hex
  trace ID; JSONL always, Langfuse when keys are set.
- `observability/pricing.py`: dollar cost from `config/pricing.yaml` (with the date checked).
- Per-episode cost/tokens/latency in `results/<run>/episodes.jsonl`; trajectories link the trace ID.
- `trustdesk trace <trace_id>` viewer.

**Why this design.** Traces are what you debug agents with; JSONL is grep-able, committed alongside results, and
needs no service. Langfuse adds a UI but is optional (ADR-005).

## Key concepts
- **What to record per model call**: model, input/output/thinking tokens, cache read/write tokens, cost, latency,
  stop reason, request ID. Thinking tokens are billed as output.
- **Cache hit rate** = cache_read / (cache_read + input + cache_write) per call; visible in `trustdesk trace`.
- **Trace ID reuse**: our hex ID is a valid OpenTelemetry/Langfuse trace ID, so both sinks show the same trace.

## Verify it yourself
- `make chat-fake`, talk once, then find the trace file under `data/traces/` and run `uv run trustdesk trace <id>`.
- With a key, compare `cache_read` on the 2nd+ model call of a conversation (should be > 0 once the prefix is big enough).

## Interview questions
1. **What's the first thing you look at when an agent episode fails?** The trace: the sequence of tool calls and
   their error codes. A `NOT_VERIFIED` first means skipped verification; `POLICY_DENIED` repeatedly means policy
   misreading; a model call with `stop_reason=max_tokens` means thinking ate the budget.
2. **How do you compute cost per conversation?** Sum per-call usage × per-token prices for input, output (incl.
   thinking), cache reads and cache writes, using a dated price file. The simulator's cost is reported separately
   because it isn't product cost.
3. **Why keep JSONL if you have Langfuse?** Results must be reproducible from committed files; a hosted UI can
   disappear or change. JSONL links each number to raw evidence.
