# M0 — Research, decisions, scaffold

## What we built
- A uv project on Python 3.12 with pinned, verified versions (`pyproject.toml`, `uv.lock`).
- ADR-001..008 in `docs/DECISIONS.md`, including a table of exactly which API shapes were checked.
- `CLAUDE.md` (short, pointers only), Makefile, CI workflow, `.env.example`.
- `src/trustdesk/config.py`: one `Settings` object from `TRUSTDESK_*` env vars (Ollama + qwen3:8b by default, all free); `DefenseLevel` enum.

**Why this design.** Agent frameworks and model APIs change monthly, so versions are verified against installed
code (`inspect.signature`) rather than memory. One settings object makes "switch provider by config" literal.
Alternative: per-module env reads — rejected, because then nobody can say what a run was configured with (the
runner snapshots `Settings` into `results/<run>/config.json`).

## Key concepts
- **Defense levels are cumulative flags**, not separate code paths: `DefenseLevel` (IntEnum) lets code say
  `if level >= DefenseLevel.D2`. See `config.py`.
- **Why Python 3.12 not 3.15:** binary wheels (onnxruntime for embeddings) lag new Python releases.
- **Reproducibility:** `uv.lock` pins the dependency graph; results files record settings.

## Verify it yourself
- `uv sync --all-extras && make test` — all green offline.
- `uv run python -c "import langgraph.types as t, inspect; print(inspect.signature(t.interrupt))"` — see `response_schema`.

## Interview questions
1. **Why pin and verify versions for an agent project?** Agent libraries change APIs quickly (LangGraph's interrupt
   semantics, Ollama's request options). Code written from memory may target a removed parameter, and a
   silent behaviour change can invalidate eval comparisons. Verifying against installed code and recording versions
   in ADRs makes results reproducible and failures explainable.
2. **Why LangGraph over a simple while-loop?** A while-loop is fine until you need to pause for a human for hours,
   survive a restart and resume exactly where you were. LangGraph gives an explicit state machine plus checkpointing
   and `interrupt()`, so the pause point is durable and the control flow is visible as a graph.
3. **What goes in CLAUDE.md and what doesn't?** Commands, layout, conventions and pointers. Not the spec: long
   context files dilute attention and go stale. The spec lives in `docs/project/SPEC.md` and is referenced.

## Break-it exercise
Set `TRUSTDESK_DEFENSE_LEVEL=7` and run `uv run trustdesk chat --provider fake`. Expected: `ValueError: 7 is not a
valid DefenseLevel` at startup. Diagnose from the traceback into `load_settings()`; the enum is what rejects it.
